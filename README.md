# 🩺 Diabetes Prediction System

A Machine Learning-based application designed to analyze health-related data and predict diabetes-related outcomes using Logistic Regression. This project integrates data preprocessing, feature scaling, model evaluation, and an interactive Streamlit web application to provide a simple and user-friendly prediction interface.

## 📌 Project Overview

The **Diabetes Prediction System** uses Machine Learning techniques to identify patterns in health-related data and classify outcomes based on selected input features. The project is developed using Python and the Scikit-learn library, with Streamlit used to create an interactive web application.

## 🎯 Objectives

- Analyze diabetes-related datasets.
- Perform data preprocessing and feature scaling.
- Train a Logistic Regression classification model.
- Evaluate model performance using Accuracy, ROC-AUC, and Confusion Matrix.
- Develop an interactive Streamlit application.
- Visualize dataset statistics and patterns.

## ⚙️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit

## 🤖 Machine Learning Algorithm

**Logistic Regression** is used as the classification algorithm to predict the target outcome based on the input features. StandardScaler is applied to standardize the features before model training and prediction.

## 📊 Model Performance

- Accuracy: 71.43%
- ROC-AUC Score: 0.823
- Train-Test Split: 80:20
- Training Records: 614
- Testing Records: 154

## 🌐 Application Features

- Interactive prediction interface.
- Health-related feature inputs.
- Prediction output with probability estimation.
- Dataset preview and statistical analysis.
- Outcome distribution visualization.
- Correlation heatmap.
- Model performance evaluation.
- Confusion matrix visualization.

## ⚠️ Disclaimer

This project is developed for educational and learning purposes. The prediction results are based on the dataset and trained Machine Learning model and should not be used as a substitute for professional medical diagnosis or advice.
